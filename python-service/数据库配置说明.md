# 数据库配置说明

## 一、环境变量的作用

这些环境变量用于告诉Python程序如何连接到MySQL数据库。就像告诉程序"数据库在哪里、用什么账号登录"。

### 各环境变量说明：

| 环境变量 | 你的值 | 作用说明 |
|---------|--------|---------|
| `DB_HOST` | `localhost` | **数据库服务器地址**<br>- `localhost` 表示数据库在本机<br>- 如果是远程服务器，填IP地址，如 `192.168.1.100` |
| `DB_PORT` | `3306` | **数据库端口号**<br>- MySQL默认端口是3306<br>- 如果MySQL改了端口，这里也要改 |
| `DB_USER` | `root` | **数据库用户名**<br>- 用于登录MySQL的用户名<br>- `root` 是MySQL的超级管理员账号 |
| `DB_PASSWORD` | `123` | **数据库密码**<br>- 就是你MySQL的root账号密码<br>- **注意：这是你MySQL的密码，不是系统密码** |
| `DB_NAME` | `sm_platform` | **数据库名称**<br>- 程序要使用的数据库名字<br>- 程序会自动创建这个数据库（如果不存在） |

## 二、如何设置环境变量

### 方法一：使用 .env 文件（推荐，最简单）

1. 在 `python-service` 目录下创建一个名为 `.env` 的文件
2. 在文件中输入以下内容：

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=123
DB_NAME=sm_platform
```

3. 保存文件即可，程序会自动读取

**注意**：`.env` 文件是隐藏文件，如果看不到，需要在文件管理器中显示隐藏文件。

### 方法二：在PowerShell中临时设置（每次启动都要设置）

打开PowerShell，在启动服务前依次输入：

```powershell
$env:DB_HOST="localhost"
$env:DB_PORT="3306"
$env:DB_USER="root"
$env:DB_PASSWORD="123"
$env:DB_NAME="sm_platform"
```

然后启动服务：
```powershell
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

### 方法三：在系统环境变量中永久设置（可选）

1. 右键"此电脑" → "属性"
2. 点击"高级系统设置"
3. 点击"环境变量"
4. 在"用户变量"中点击"新建"
5. 逐个添加上述变量

## 三、数据库的作用

### 1. **存储用户信息**
- 存储用户名、密码（加密后的）
- 存储用户角色（普通用户/管理员）
- 存储用户状态（是否激活）

### 2. **持久化数据**
- **之前**：用户数据存在内存中，程序重启就丢失
- **现在**：用户数据存在数据库中，程序重启后数据还在

### 3. **安全性**
- 密码使用bcrypt加密存储，不是明文
- 支持多用户管理
- 可以设置用户权限

### 4. **可扩展性**
- 可以添加更多用户
- 可以存储更多信息（如审计记录、修复历史等）
- 支持数据备份和恢复

## 四、工作流程

```
用户登录
    ↓
程序读取环境变量（DB_HOST, DB_USER等）
    ↓
连接到MySQL数据库
    ↓
查询users表，验证用户名和密码
    ↓
返回登录结果
```

## 五、常见问题

### Q: 密码填错了怎么办？
A: 修改 `.env` 文件中的 `DB_PASSWORD` 值，保存后重启服务。

### Q: 数据库连接失败？
A: 检查：
1. MySQL服务是否启动（在服务管理器中查看）
2. 密码是否正确
3. 端口号是否正确（默认3306）

### Q: 如何查看MySQL是否运行？
A: 打开任务管理器 → 服务，查找 `MySQL` 或 `MySQL80`，确认状态为"正在运行"。

### Q: 忘记MySQL密码怎么办？
A: 需要重置MySQL密码，可以搜索"MySQL重置root密码"教程。
