# 快速开始 - 数据库配置

## 最简单的设置方法

### 步骤1：创建 .env 文件

在 `python-service` 文件夹下创建一个名为 `.env` 的文件（注意：文件名就是 `.env`，没有其他名字）

### 步骤2：复制以下内容到 .env 文件

```env
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=123
DB_NAME=sm_platform
```

### 步骤3：保存文件

保存后，程序启动时会自动读取这些配置。

## 环境变量详解

### DB_HOST=localhost
- **作用**：告诉程序数据库在哪里
- **localhost** = 本机（数据库和程序在同一台电脑）
- 如果数据库在别的电脑，改成那台电脑的IP地址

### DB_PORT=3306
- **作用**：告诉程序通过哪个端口连接数据库
- **3306** = MySQL的默认端口（一般不用改）

### DB_USER=root
- **作用**：用哪个账号登录数据库
- **root** = MySQL的管理员账号（最常用的）

### DB_PASSWORD=123
- **作用**：数据库账号的密码
- **123** = 你的MySQL root账号密码
- ⚠️ **重要**：这里填的是MySQL的密码，不是Windows密码！

### DB_NAME=sm_platform
- **作用**：使用哪个数据库
- **sm_platform** = 数据库的名字（程序会自动创建）

## 数据库的作用（简单理解）

### 之前（没有数据库）：
```
用户登录 → 程序在内存中查找用户 → 程序重启后，用户数据丢失 ❌
```

### 现在（有数据库）：
```
用户登录 → 程序在数据库中查找用户 → 程序重启后，用户数据还在 ✅
```

### 具体作用：

1. **保存用户账号**
   - 用户名、密码（加密存储）
   - 用户角色（普通用户/管理员）

2. **数据持久化**
   - 数据存在硬盘上，不会丢失
   - 程序重启、电脑重启，数据都在

3. **安全性**
   - 密码加密存储（不是明文）
   - 支持多用户管理

4. **可扩展**
   - 可以添加更多用户
   - 未来可以存储更多数据（如操作记录等）

## 如何检查配置是否正确？

### 1. 确认MySQL已安装并运行
- 打开"服务"（Win+R，输入 `services.msc`）
- 查找 `MySQL` 或 `MySQL80`
- 确认状态为"正在运行"

### 2. 测试连接
运行初始化脚本：
```bash
python -m app.init_db
```

如果看到：
```
✓ 数据库 sm_platform 创建成功
✓ 数据表创建成功
✓ 初始用户数据插入成功
```
说明配置正确！

### 3. 如果连接失败
检查：
- MySQL服务是否启动
- `.env` 文件中的密码是否正确
- `.env` 文件是否在 `python-service` 目录下

## 常见错误

### 错误1：找不到 .env 文件
- 确保文件名为 `.env`（注意前面有个点）
- 确保文件在 `python-service` 目录下

### 错误2：连接被拒绝
- MySQL服务没有启动
- 端口号不对（默认3306）

### 错误3：密码错误
- 检查 `.env` 文件中的 `DB_PASSWORD` 是否正确
- 这是MySQL的密码，不是Windows密码
